DBMS Project 55

Bank Account and Transaction Management System

A MySQL database and a layered Java/JDBC desktop application that simulate the core of a retail bank. Every financial event is a double-entry ledger transaction, history is never edited, and the database enforces integrity itself.

Features

Customers, branches, products

Create, read, update and search, with validation for email, phone, IFSC, age 18+ and masked ID numbers.

Accounts

Product-specific minimum deposits, joint holders, and an ACTIVE / FROZEN / BLOCKED / CLOSED lifecycle with status history.

Money movement

Deposits, withdrawals, atomic transfers to ACTIVE beneficiaries and service charges, all through one locking posting engine.

Corrections

Reversal transactions mark the original REVERSED. Nothing is ever edited or deleted.

Loans

Disbursement with a reducing-balance EMI schedule, and instalment repayment split into principal and interest.

Reports

Statements, trial balance, branch and loan summaries, and a one-click ledger integrity check of 13 invariants.

Run it locally

This is a desktop (Swing) application backed by a local MySQL server, so it runs on your machine rather than in the browser. You need MySQL 8.0.16+, JDK 17+ and Maven 3.8+.

git clone https://github.com/yathin-oss/DBMS_PBL.git && cd DBMS_PBL

# 1. Create the databases and app user (set a password in the file first)
mysql -u root -p < sql/00_create_database.sql

# 2. Install schema, triggers, views and demo data
scripts/setup_database.sh --with-sample-data

# 3. Configure the connection, then build and run
cp db.properties.example db.properties    # set db.password
mvn clean package
java -jar target/bank-dbms.jar
